cape.promptutils: Useful tools for interactive CLI prompts¶

This includes a CAPE-specific autocompletion class CfdxCompleter, which is used in cape.ui.

cape.ui.promptutils.sprintf_color_rl(msg: str, color: str | list | None = None) → str¶

Create string with color for readline input prompts

This wraps ANSI escape codes with readline’s special markers (x01 and x02) so readline can correctly calculate prompt width and handle line wrapping/cursor positioning.

Call:
>>> prompt = sprintf_color_rl(msg, color=None)
Inputs:
msg: str

Text to display prior to requesting input

color: {None} | str | list

Name(s) of color (or style) to use for prompt

Outputs:
prompt: str

String with readline-wrapped color instructions
