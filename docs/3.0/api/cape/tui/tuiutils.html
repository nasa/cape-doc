cape.tui.tuiutils: Render helpers for the CAPE TUI¶

This module provides the presentation helpers for cape.tui, the Textual-based interactive terminal user interface to CAPE. These functions build Rich renderables (tables, panels) which the app writes to its scroll log or prints to the terminal on exit.

cape.tui.tuiutils.banner_panel(histfile: str | None = None) → Panel¶

Build the CAPE TUI startup banner

Call:
>>> panel = banner_panel(histfile=None)
Inputs:
histfile: {None} | str

Name of command history file

Outputs:
panel: rich.panel.Panel

Startup banner with host info and key hints

cape.tui.tuiutils.cmd_help_panel(cmdname: str, subcls: type, cls: type) → Panel¶

Build a Rich help panel for a single CAPE sub-command

Call:
>>> panel = cmd_help_panel(cmdname, subcls, cls)
Inputs:
cmdname: str

Name of command

subcls: type

cape.argread.ArgReader for cmdname

cls: type

cape.argread.ArgReader for front desk

Outputs:
panel: rich.panel.Panel

Panel with description, aliases, and options table

cape.argread.ArgReader subtype

Get the last two folders of a path, as in cape.ui

path: {None} | str

Folder to summarize; default is current working folder

Outputs:
dirname: str

Last two folders of path

cape.tui.tuiutils.get_tui_histfile() → str¶

Get the name of the CAPE TUI history file

The file is controlled by the TUIHistoryFile option from the user’s ~/.capeconfig.json (or the $CAPE_TUI_HISTORY_FILE environment variable). Relative paths are joined with the CAPE CacheDir.

Call:
>>> histfile = get_tui_histfile()
Outputs:
histfile: str

Name of TUI command history file
