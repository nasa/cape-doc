cape.agent.agenttui: Textual interface for CAPE agent¶

This module adapts cape.tui.tuiapp.CapeTuiApp to use an cape.agent.agentcntl.AgentCntl conversation as its command backend. The ordinary CAPE TUI supplies the composer, folding log, history, prompt bridge, interruption behavior, and session chrome.
