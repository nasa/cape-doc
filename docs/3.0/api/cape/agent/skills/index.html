cape.agent.skills: Agent skills for the CAPE agent¶

This package collects the agent skills available to the CAPE agent. A skill is a documented workflow that tells the agent how and when to use certain tools and how to chain tool calls together. Skills come from two sources:

Built-in skills are defined in this package, alongside any tools they provide (see cape.agent.skills.cntlrunner).

User skills are discovered from .agents/skills/<NAME>/SKILL.md files in the folder in which the user launches the agent (see cape.agent.skills.skillbase.discover_user_skills()).

Skills are gated by the SkillSet option of the model in use (see cape.agent.options.modelopts), and activated by the agent using the use_skill tool (see cape.agent.skills.skilltools).

cape.agent.skills.discover_user_skills(rootdir: str) → dict¶

Discover user skills from an .agents/skills/ folder

Scans <rootdir>/.agents/skills/<NAME>/SKILL.md and reads every valid skill file. Malformed files are skipped with a warning.

Call:
>>> user_skills = discover_user_skills(rootdir)
Inputs:
rootdir: str

Folder in which the agent was launched

Outputs:
user_skills: dict[Skill]

Map of skill names to skill definitions

Versions:

  • 2026-09-01 @ddalle: v1.0

cape.agent.skills.read_skillfile(fname: str) → Skill¶

Read an agent skill definition from a SKILL.md file

The file must start with a YAML front matter section delimited by --- lines, containing at least name and description. The remainder of the file is Markdown instructions for the agent.

Call:
>>> skill = read_skillfile(fname)
Inputs:
fname: str

Name of SKILL.md file to read

Outputs:
skill: Skill

Definition of one agent skill

Raises:
ValueError

If fname has no valid front matter or is missing a required key
