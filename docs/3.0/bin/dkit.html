dkit: Command-line interface to datakit tools¶

Perform actions on a DataKit package or package collection from the command-line interface.

Usage:
$ dkit CMD [ARGS] [OPTIONS]
Sub-commands:
help

Display help message and exit

quickstart

Create a template DataKit package

vendorize

Install local copies of packages

writedb

Process raw data into datakit files

Options:
-h, --help

Print this help message and exit
