cape.cfdx: Templates for CFD control tools¶

This is a container module for templates to the individual CFD solver executives:

  • cape.pycart

  • cape.pyfun

  • cape.pyover

Not all of the modules templated in these specific modules are derived from cape.cfdx modules, but modules and actions that are specific to CFD generally are.

  • cape.cfdx.cntl: Base module for CFD operations and processing
  • cape.cfdx.cntlbase: Abstract base module for run matrix control
  • cape.cfdx.casecntl: Case control module
  • cape.cfdx.casedata: Single-case data interfaces
  • cape.cfdx.caseutils: Common functions for case-control modules
  • cape.cfdx.casecntlbase: Abstract base classes for case interface
  • cape.cfdx.archivist: File archiving and clean-up for cases
  • cape.cfdx.autocomplete: Shell completion for CAPE CLI
  • cape.cfdx.cli: Command-line interface to cape (executable)
  • cape.cfdx.cmd: Creating system commands
  • cape.cfdx.cmdrun: Execute system calls for CAPE
  • cape.cfdx.databook: Post-processed data module
  • cape.cfdx.databookbase: Abstract base classes for DataBook
  • cape.cfd.dex: Exchange data b/w CFD case and DataBook
  • cape.cfdx.lineload: Line load databooks
  • cape.cfdx.logger: Logging utilities for CAPE
  • cape.cfdx.ll: Line load interfaces
  • cape.cfdx.manage: Manage file counts and quotas
  • cape.cfdx.pointsensor: Point sensor databooks
  • cape.cfdx.queue: Manage PBS and Slurm interfaces
  • cape.cfdx.report: Automated CFD report interface
  • cape.cfdx.runmatrix: Run matrix interface
  • cape.cfdx.tarcmd: Common tar/untar utilities
  • cape.cfdx.triqfm: Module for reading patch loads from one case
  • cape.cfdx.volcomp: Cell volume computation tools
  • cape.cfdx.options: Options package
