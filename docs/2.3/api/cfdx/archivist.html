cape.cfdx.archivist: File archiving and clean-up for cases¶

This module provides the class CaseArchivist, which conducts the operations of commands such as

pyfun --archive
pycart --clean
pyover --skeleton
class cape.cfdx.archivist.CaseArchivist(opts: ArchiveOpts, where: str | None = None, casename: str | None = None)¶

Bases: object

Class to archive a single CFD case

Call:
>>> a = CaseArchivist(opts, where=None, casename=None)
Inputs:
opts: ArchiveOpts

Case archiving options

where: {None} | str

Root of CFD case folder (default: CWD)

casename: {None} | str

Name of CFD case folder (default: last two levels of CWD)

cape.cfdx.archivist.rematch(pat: str) → dict¶

Search for file and folder names matching regular expression

If the regex contains groups (parentheses), the results are grouped by the values of those groups. If the regex does not contain groups, the results are all in a single group called ''.
