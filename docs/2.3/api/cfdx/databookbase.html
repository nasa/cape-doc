cape.cfdx.databookbase: Abstract base classes for DataBook¶

This module provides abstract base classes for the “DataBook” capability in CAPE, which collects post-processed data from CFD cases.

The main class is DataBookBase, which is the base class for cape.cfdx.databook.DataBook.

See also:

  • cape.cfdx.databook
