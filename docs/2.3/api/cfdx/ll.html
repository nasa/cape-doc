cape.cfdx.ll: Line load interfaces¶

This module provides interfaces for reading and processing line load data from CFD simulations.

class cape.cfdx.ll.CaseLineLoad(comp: str, proj: str = 'LineLoad', sec: str = 'dlds', dirname: str | None = 'lineload', **kw)¶

Bases: DataKit

Interface to individual sectional load from one case

Call:
>>> ll = CaseLineLoad(comp, proj='LineLoad', sec='slds', **kw)
Inputs:
comp: str

Name of component

proj: {"LineLoad"} | str

Prefix for sectional load output files

sec: "clds" | {"dlds"} | "slds"

Cut type, cumulative, derivative, or sectional

dirname: {"lineload"} | None | str

Name of sub folder to use

Outputs:
LL: cape.cfdx.lineload.CaseLL

Individual line load for one component from one case
