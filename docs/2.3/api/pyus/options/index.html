This module provides tools to read, access, modify, and write settings for cape.pyus. It provides Options, which is based off of dict class, so options are stored in keys such as opts["InputInp"]. In addition, many convenience methods, such as opts.get_CFDSOLVER_ires(), are also provided.

See also:

  • cape.cfdx.options

  • cape.pyus.options.runctlopts
