cape.pyus: US3D interfaces¶

The cape.pyus module contains the top-level interface for US3D setup, execution, and post-processing. It loads some of the most important methods from the various submodules so that they are easier to access. Most tasks using the pyFun API can be accessed by loading this module and reading one instance of the cape.pyus.cntl.Cntl class.

import cape.pyus

For example the following will read in a global settings instance assuming that the present working directory contains the correct files. (If not, various defaults will be used, but it is unlikely that the resulting setup will be what you intended.)

import cape.pyus
cntl = cape.pyus.Cntl()

The following classes are imported in this module, so that code like pyFun.Cntl will work (although cape.pyfun.cntl.Cntl will also work).

  • cape.pyus.cntl.Cntl

Modules included within this one are outlined below.

  • Core modules:

    • cape.pyus.cntl

    • cape.pyus.casecntl

    • cape.pyus.options

  • US3D and Cape files

    • cape.pyus.inputinpfile

  • Supporting modules

    • cape.pyus.cmdgen

    • cape.pyus

  • cape.pyus.casecntl: US3D Case control module
  • cape.pyus.cli: Command-line interface to pyus
  • cape.pyus.cmdgen: Create commands for US3D executables
  • cape.pyus.cmdrun: US3D binary interface module
  • cape.pyus.us3d: US3D control module
  • cape.pyus.inputinpfile: US3D primary input file interface
  • cape.pyus.options.Archive: US3D archiving options
  • cape.pyus.options.configopts: US3D configuration options
  • cape.pyus.options.inputInp: US3D input.inp options
  • cape.pyus.options.runctlopts: US3D run control options
  • cape.pyus.options.util: Utilities for pyUS options module
