cape.pyus.cmdrun: US3D binary interface module¶

This module provides an interface to the various US3D executables and other command-line utilities from cape.bin. However, due to some of the subtleties of how the main US3D executables are called, cape.pyus.casecntl.RunPhase() constructs the commands to run US3D from cape.pyus.cmdgen locally and runs them using cape.cmdrun.callf().

See also:

  • cape.cfdx.cmdrun

  • cape.cfdx.cmdgen

  • cape.pyus.cmdgen

cape.pyus.cmdrun.us3d(opts, i=0, **kw)¶

Interface to US3D executable us3d
