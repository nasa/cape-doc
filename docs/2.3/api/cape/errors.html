cape.errors: Customized exceptions for CAPE¶

This module provides CAPE-specific exceptions and methods to perform standardized checks throughout cape. One purpose of creating customized exceptions is to differentiate CAPE bugs and exceptions raised by CAPE intentionally due to problems with user input or errors detected in the execution of the integrated CFD solvers.

cape.errors.assert_isinstance(obj: Any, cls_or_tuple: type | tuple, desc: str | None = None)¶

Conveniently check types

Applies isinstance(obj, cls_or_tuple) but also constructs a :class;`TypeError` and appropriate message if test fails

Call:
>>> assert_isinstance(obj, cls, desc=None)
>>> assert_isinstance(obj, cls_tuple, desc=None)
Inputs:
obj: object

Object whose type is checked

cls: type

Single permitted class

cls_tuple: tuple[type]

Tuple of allowed classes

desc: {None} | str

Brief description of intended use of obj

Raises:

  • CapeTypeError if type of obj does not match cls or cls_tuple

Version:

  • 2024-06-19 @ddalle: v1.0
