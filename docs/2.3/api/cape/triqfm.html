cape.triqfm: Command-line interface to triqfm tool¶

This function provides the Python function triqfm() that executes the TriqFM functionality and the function main() that accesses this function from the command line.

cape.triqfm.main()¶
cape.triqfm.triqfm(*a, **kw)¶

Extract forces and moments from a TRIQ file

Note that both triq and comps can be overwritten by keyword arguments even if specified using positional arguments.

Call:
>>> C = triqfm(triq, *comps, **kw)
Inputs:
triq: {"grid.i.triq"} | str

Name of TRIQ annotated triangulation file

comps: {None} | list (str | int)

List of components to analyze (default is to entire surface)

tri, map: {None} | str

Separate triangulation file to use for identifying triq subset

c: {None} | str

Configuration (XML or JSON format) file to use

incm, momentum: True | {False}

Include momentum (flow-through) forces in total

m, mach: {1.0} | float

Freestream Mach number

RefArea, Aref: {1.0} | float

Reference area

RefLength, Lref: {1.0} | float

Reference length (longitudinal)

RefSpan, bref: {Lref} | float

Reference span (for rolling and yawing moments)

Re, Rey: {1.0} | float

Reynolds number per grid unit (units same as triq.Nodes)

gam, gamma: {1.4} | float > 1

Freestream ratio of specific heats

xMRP: {0.0} | float

x-coordinate of moment reference point

yMRP: {0.0} | float

y-coordinate of moment reference point

zMRP: {0.0} | float

z-coordinate of moment reference point

MRP {[XMRP, YMRP, ZMRP]} | list

Moment reference point

Outputs:
FM: dict[float]

Dictionary of force and moment coefficients
