cape.pylava.runinpfile: Interface to LAVA-Cartesian input files¶

This module provides the class CartInputFile, which is used to parse and modify the C-like input file to LAVA-Cartesian

class cape.pylava.runinpfile.CartFileList(opt: str, fp: IOBase | None = None)¶

Reader for a “list” of LAVA-Cartesian input files

This refers to list-like contents of [] brackets, e.g.

[
    mach,
    cp
]
Call:
>>> sec = CartFileList(opt, fp)
Inputs:
opt: str

Name of option on left-hand side, used for error messages

fp: IOBase

File open for reading at start of section

class cape.pylava.runinpfile.CartFileSection(sec: str, fp: IOBase | None = None)¶

Reader for a “section” of LAVA-Cartesian input files

This refers to dict-like contents of {} braces, e.g.

{
    mach = 4.5
    alpha = 2.0
}
Call:
>>> sec = CartFileSection(sec, fp)
Inputs:
sec: str

Name of section, used for error messages

fp: IOBase

File open for reading at start of section
