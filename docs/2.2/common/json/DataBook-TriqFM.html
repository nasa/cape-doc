3.1.4.7. TriqFM: options for a patch load or triqfm databook component¶

Option aliases:

  • Config → ConfigFile

  • MapTriFile → MapTri

  • antol → AbsProjTol

  • atol → AbsTol

  • cntol → CompProjTol

  • ctol → CompTol

  • rntol → RelProjTol

  • rtol → RelTol

  • Coeffs → Cols

  • Coefficients → Cols

  • Component → CompID

  • NAvg → nStats

  • NFirst → NMin

  • NLast → NLastStats

  • NMax → NLastStats

  • NStatsMax → NMaxStats

  • coeffs → Cols

  • cols → Cols

  • dnStats → DNStats

  • nAvg → NStats

  • nFirst → NMin

  • nLast → NLastStats

  • nLastStats → NLastStats

  • nMax → NLastStats

  • nMaxStats → NMaxStats

  • nMin → NMin

  • nStats → NStats

  • nStatsMax → NMaxStats

  • tagets → Targets

Recognized options:

AbsProjTol: {None} | float

absolute projection tolerance

AbsTol: {None} | float

absolute tangent tolerance for surface mapping

Cols: {'CA'} | str

list of primary solver output variables to include

CompID: {None} | object

surface componet(s) to use for this databook component

CompProjTol: {None} | float

projection tolerance relative to size of component

CompTol: {None} | float

tangent tolerance relative to component

ConfigCompID: {None} | int | str

value of option “ConfigCompID”

ConfigFile: {None} | str

configuration file for surface groups

DNStats: {None} | int

increment for candidate window sizes

FloatCols: {[]} | str

additional databook cols with floating-point values

IntCols: {'nIter'} | str

additional databook cols with integer values

MapTri: {None} | str

name of a tri file to use for remapping CFD surface comps

NLastStats: {None} | int

specific iteration at which to extract stats

NMaxStats: {None} | int

max number of iters to include in averaging window

NMin: {None} | int

first iter to consider for use in databook [for a comp]

NStats: {None} | int

iterations to use in averaging window [for a comp]

OutputFormat: 'dat' | {'plt'} | 'triq'

output format for component surface files

OutputSurface: {True} | False

whether or not to write TriqFM surface

PatchMap: {None} | dict

value of option “PatchMap”

Patches: {None} | list[str]

list of patches for a databook component

Prefix: {None} | object

value of option “Prefix”

RelProjTol: {None} | float

projection tolerance relative to size of geometry

RelTol: {None} | float

relative tangent tolerance for surface mapping

Targets: {{}} | dict

targets for this databook component

Transformations: {[]} | dict

list of transformations applied to component

TriqFormat: '' | 'b4' | 'lb4' | {'lr4'} | 'r4'

value of option “TriqFormat”

Type: {'FM'} | str

databook component type
